Billing defaults to disabled. Configured prices are validated; a changed displayed quote requires a new review. Marketing prices remain explicitly illustrative and use organization billing terminology.

Durable canonical selection fingerprints, fixed expiry, server-selected prices, stable idempotency keys, one pending checkout and explicit resume protect retries. Checkout refreshes the customer's canonical subscriptions before reserving a request, including after a missed completion webhook and local expiry. An uncertain customer request older than 23 hours requires reconciliation. The raw signed webhook route precedes JSON parsing, rejects live/connected-account events and retrieves current canonical state rather than granting access from event payloads or browser return flags. Leased synchronization atomically commits account/invoices/event identity; duplicates do not reapply and failures remain retryable. Unsupported canonical subscriptions hold paid entitlements until valid reconciliation. Raw webhook bodies and card details are not retained.

The original responsive page includes plan/usage cards, trial consent, explicit amount/interval confirmation, current state/cancellation, private scrollable invoices, role-specific feedback and unavailable/retry states. Dialogs trap/restore focus. Lost-response resume preserves the original operation. Membership revoked during provider I/O prevents returning hosted URLs; revoked billing reads remove private content.
